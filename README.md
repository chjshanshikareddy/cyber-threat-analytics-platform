# Cybersecurity Threat Intelligence & Analytics

A cybersecurity analytics project developed across four milestones using incident data and Microsoft Power BI to analyze threat patterns, temporal trends, geospatial risk, response analytics, and executive-level risk intelligence.

## Project Overview

The project progresses from data integration and incident modeling to threat intelligence, geospatial intelligence, and risk intelligence with predictive financial-loss analysis.

## Milestones

### Milestone 1 – Data Integration & Incident Modeling

- Dataset collection and preparation
- Data preprocessing and standardization
- Incident data modeling
- Foundation for cybersecurity risk and incident analysis

### Milestone 2 – Threat Intelligence & Temporal Analytics

- Threat classification and severity analysis
- Temporal incident trends
- Threat intelligence analysis
- Power BI dashboard

### Milestone 3 – Geospatial Intelligence & Response Analytics

- Geographic threat analysis
- Threat hotspot visualization
- Risk-surface analysis
- Response analytics
- Power BI dashboard

### Milestone 4 – Risk Intelligence & Executive Analytics

- Threat Severity Index (TSI)
- Composite Risk Score
- City risk ranking
- Critical hotspot analysis
- Cyber threat risk heatmap
- Financial impact analysis
- Predictive financial-loss forecasting
- Executive Power BI dashboard

## Dataset

The project uses cybersecurity incident data containing information such as incident type, city, category, severity, time period, and financial loss.

The Milestone 4 analysis covers **1,200 cybersecurity incidents from 2019–2024**.

## Risk Methodology

### Risk Score

The composite Risk Score combines severity and financial loss:

**Risk Score = 60% Severity Component + 40% Financial Loss Component**

### Threat Severity Index (TSI)

TSI is an executive-level 0–100 risk indicator based on:

- 40% average Severity Index
- 40% average Risk Score
- 20% incident volume weighting
