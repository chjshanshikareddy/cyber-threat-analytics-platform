# Dataset

This folder contains the dataset used for the cybersecurity analytics project.

The dataset supports incident analysis, threat classification, severity analysis, geospatial analysis, financial-loss analysis, and risk intelligence.

## Dataset Coverage

- Cybersecurity incidents
- Incident types
- Categories
- Severity information
- City/location information
- Financial loss
- Incident dates

## Note

Only data that is permitted for public distribution should be uploaded to this repository.
